# Find First and Last Position of Element in Sorted Array (LeetCode 34)

## 1. Intuition

Since the array is sorted in non-decreasing order, Binary Search can be used efficiently. Instead of searching linearly for the first and last occurrence of the target, we perform **two Binary Searches**:

- One to find the **first occurrence (lower bound)** of the target.
- Another to find the **position just after the last occurrence (upper bound)** of the target.

The last occurrence is then obtained by subtracting `1` from the upper bound.

### Why did I choose this approach?

- It uses Binary Search to efficiently locate the target's range.
- It avoids traversing the entire array.
- It finds both the starting and ending positions in **O(log n)** time.
- It satisfies the required runtime complexity.

---

## 2. Approach

### Algorithm

1. Create a function `lower()` to find the **first index** where `nums[index] >= target`.
   - Initialize:
     - `low = 0`
     - `high = n - 1`
     - `ans = n`
   - Perform Binary Search.
   - Whenever `nums[mid] >= target`, store `mid` as a possible answer and continue searching on the left side.
   - Return the first occurrence index.

2. Create another function `higher()` to find the **first index** where `nums[index] > target`.
   - Initialize:
     - `low = 0`
     - `high = n - 1`
     - `ans = n`
   - Perform Binary Search.
   - Whenever `nums[mid] > target`, store `mid` as a possible answer and continue searching on the left side.
   - Return the upper bound index.

3. In the `searchRange()` function:
   - Find the first occurrence using `lower()`.
   - If the returned index is outside the array or the target is not present, return `[-1, -1]`.
   - Otherwise:
     - First position = `lower()`
     - Last position = `higher() - 1`

4. Return the first and last positions.

### Time Complexity

- **O(log n)**

Two Binary Search operations are performed, each taking `O(log n)` time.

### Space Complexity

- **O(1)**

Only a few extra variables are used.

## 3. Code

```java
class Solution {
    public int lower(int[] nums, int n, int target) {
        int high = n - 1;
        int ans = n;
        int low = 0;

        while (low <= high) {
            int mid = (low + high) / 2;

            if (nums[mid] >= target) {
                ans = mid;
                high = mid - 1;
            } else {
                low = mid + 1;
            }
        }

        return ans;
    }

    public int higher(int[] nums, int n, int target) {
        int low = 0;
        int high = n - 1;
        int ans = n;

        while (low <= high) {
            int mid = (low + high) / 2;

            if (nums[mid] > target) {
                ans = mid;
                high = mid - 1;
            } else {
                low = mid + 1;
            }
        }

        return ans;
    }

    public int[] searchRange(int[] nums, int target) {
        int n = nums.length;

        int lowee = lower(nums, n, target);

        if (lowee == n || nums[lowee] != target) {
            return new int[] {-1, -1};
        }

        return new int[] {lowee, higher(nums, n, target) - 1};
    }
}
```

---

## Example

**Input**

```text
nums = [5,7,7,8,8,10]
target = 8
```

**Output**

```text
[3,4]
```

**Explanation**

- The first Binary Search (`lower()`) finds the first occurrence of `8` at index `3`.
- The second Binary Search (`higher()`) finds the first element greater than `8`, which is `10` at index `5`.
- Therefore, the last occurrence of `8` is `5 - 1 = 4`.
- Hence, the target appears from index **3** to **4**.
