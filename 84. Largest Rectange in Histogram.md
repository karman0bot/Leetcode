# Largest Rectangle in Histogram (LeetCode 84)

## 1. Intuition

The goal of this problem is to find the largest rectangular area that can be formed in a histogram.

For every bar, we consider that bar as the **height of the rectangle** and try to find how far this rectangle can extend to the left and right before encountering a smaller bar.

To determine this range efficiently, we find:

- **NSE (Next Smaller Element)** — the first smaller element on the right.
- **PSE (Previous Smaller Element)** — the first smaller element on the left.

Once we know the NSE and PSE for every bar, we can calculate the width of the largest rectangle possible using that bar as the height.

The width is:

```text
Width = NSE[i] - PSE[i] - 1
```

Therefore, the area of the rectangle is:

```text
Area = Width × Height
```

A **Monotonic Stack** is used to efficiently find both NSE and PSE.

### Why did I choose this approach?

- It avoids checking every possible rectangle individually.
- It uses a Monotonic Stack to efficiently find smaller elements.
- NSE and PSE help determine the maximum width for every bar.
- It reduces the overall time complexity to **O(n)**.
- The original histogram array is not modified.

---

## 2. Approach

### Algorithm

1. Find the **Next Smaller Element (NSE)** for every bar:
   - Traverse the histogram from right to left.
   - Maintain a stack containing indices of bars.
   - Remove elements from the stack while their height is greater than or equal to the current bar.
   - If the stack is empty, there is no smaller element on the right, so set `NSE[i] = n`.
   - Otherwise, the top of the stack is the index of the next smaller element.
   - Push the current index into the stack.

2. Find the **Previous Smaller Element (PSE)** for every bar:
   - Traverse the histogram from left to right.
   - Maintain another stack containing indices of bars.
   - Remove elements from the stack while their height is greater than or equal to the current bar.
   - If the stack is empty, there is no smaller element on the left, so set `PSE[i] = -1`.
   - Otherwise, the top of the stack is the index of the previous smaller element.
   - Push the current index into the stack.

3. Calculate the maximum rectangle area:
   - For every bar, calculate its possible width using:
     ```text
     width = NSE[i] - PSE[i] - 1
     ```
   - Calculate the area:
     ```text
     area = width × heights[i]
     ```
   - Keep track of the maximum area.

4. Return the maximum area.

### Time Complexity

- **getNSE()**: O(n)
- **getPSE()**: O(n)
- **largestRectangleArea()**: O(n)

Although there is a `while` loop inside the traversal, each element is pushed and popped from the stack at most once. Therefore, the operations are **O(n) amortized**.

Overall:

**Time Complexity: O(n)**

### Space Complexity

- `NSE` vector: O(n)
- `PSE` vector: O(n)
- Stack used in each helper function: O(n)

Overall:

**Space Complexity: O(n)**

## 3. Code

```cpp
class Solution {
public:
    vector<int> getNSE(vector<int>& heights, int n) {

        stack<int> st;
        vector<int> NSE(n, 0);

        for (int i = n - 1; i >= 0; i--) {

            while (!st.empty() && heights[st.top()] >= heights[i])
                st.pop();

            if (st.empty())
                NSE[i] = n;
            else
                NSE[i] = st.top();

            st.push(i);
        }

        return NSE;
    }

    vector<int> getPSE(vector<int>& heights, int n) {

        stack<int> st;
        vector<int> PSE(n, 0);

        for (int i = 0; i < n; i++) {

            while (!st.empty() && heights[st.top()] >= heights[i])
                st.pop();

            if (st.empty())
                PSE[i] = -1;
            else
                PSE[i] = st.top();

            st.push(i);
        }

        return PSE;
    }

    int largestRectangleArea(vector<int>& heights) {

        int n = heights.size();

        // NSE --> next smaller element
        // PSE --> previous smaller element
        vector<int> NSE = getNSE(heights, n);
        vector<int> PSE = getPSE(heights, n);

        int maxi = 0;

        for (int i = 0; i < n; i++) {

            // area of rectangle = length * height
            int length = NSE[i] - PSE[i] - 1;
            int area = length * heights[i];

            maxi = max(maxi, area);
        }

        return maxi;
    }
};
```

## Example

**Input**

```text
heights = [2,1,5,6,2,3]
```

**Output**

```text
10
```

**Explanation**

For the histogram:

```text
[2,1,5,6,2,3]
```

Consider the bar with height `5` at index `2`.

- Previous Smaller Element = index `1` (height `1`)
- Next Smaller Element = index `4` (height `2`)

Therefore:

```text
Width = 4 - 1 - 1
      = 2
```

The rectangle contains heights `5` and `6`, so the minimum height is `5`.

Therefore:

```text
Area = 5 × 2
     = 10
```

The maximum rectangle area in the histogram is **10**.
