# Search Insert Position (LeetCode 35)

## 1. Intuition

Since the array is sorted in ascending order with distinct elements, **Binary Search** can be used to efficiently locate the target. If the target is present, return its index. Otherwise, determine the position where it should be inserted to maintain the sorted order.

The key observation is that when Binary Search ends without finding the target, the `start` pointer indicates the correct insertion position.

### Why did I choose this approach?

- It utilizes Binary Search to reduce the search space by half in every iteration.
- It efficiently finds both the target and its insertion position.
- It avoids shifting or modifying the array.
- It satisfies the required **O(log n)** time complexity.

---

## 2. Approach

### Algorithm

1. Initialize two pointers:
   - `start = 0`
   - `end = nums.length - 1`

2. While `start <= end`:
   - Find the middle index:
     ```java
     int mid = start + (end - start) / 2;
     ```

3. Compare `nums[mid]` with the target:
   - If `nums[mid] == target`, return `mid`.
   - If `nums[mid] > target`, search the left half by updating:
     ```java
     end = mid - 1;
     ```
   - Otherwise, search the right half by updating:
     ```java
     start = mid + 1;
     ```

4. If the target is not found, return `start`, as it represents the correct insertion position.

### Time Complexity

- **O(log n)**

Binary Search halves the search space in every iteration.

### Space Complexity

- **O(1)**

Only a few extra variables are used.

---

## 3. Code

```java
class Solution {
    public int searchInsert(int[] nums, int target) {
        int start = 0;
        int end = nums.length - 1;

        while (start <= end) {
            int mid = start + (end - start) / 2;

            if (nums[mid] == target)
                return mid;
            else if (nums[mid] > target)
                end = mid - 1;
            else
                start = mid + 1;
        }

        return start;
    }
}
```

---

## Example

**Input**

```text
nums = [1,3,5,6]
target = 2
```

**Output**

```text
1
```

**Explanation**

- Initially, `start = 0` and `end = 3`.
- The middle element is `3`, which is greater than the target `2`, so search the left half.
- The search continues until `start` becomes `1` and `end` becomes `0`.
- Since the target is not found, the loop ends.
- The `start` pointer indicates the correct position where `2` should be inserted.
- Hence, the answer is **1**.
